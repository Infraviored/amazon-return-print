Amazon Return Helper
Free browser extension · Amazon.de

Returns without the paper mess.

Print only what the parcel counter needs on a single page, or put the DHL return QR code straight into Google Wallet and show it from your phone.

Add to Firefox Chrome & Edge

Free and open source (MIT) · Source code on GitHub

Two buttons, right under your return label

The Amazon page stays as it is. The extension adds two buttons below each label, so it works with several returns on one page too.

🖨Minimal print

One A4 page with the label or QR code and the item list. No Amazon menus, no instructions, no second page.

📱Google Wallet

For "label free, box free" returns: the DHL return QR code as a pass on your phone, with return number, carrier and expiry date.

How the Google Wallet pass is made

Only on your click, one pass per return, nothing kept afterwards.

  1. You click "Google Wallet"on the Amazon.de return page. Nothing happens without that click.
  2. The extension reads the codethe DHL return QR code Amazon shows, plus return number, expiry date and item title.
  3. This server signs the passwallet.infraviored.com signs a pass with exactly that QR code and links to Google's save page.
  4. Scan it at the counterSave the pass and show it at the DHL counter. It expires after the return deadline.

A generic pass with the QR code, return number, carrier and expiry date. No accounts, no marketing, no notifications, no updates to saved passes.
