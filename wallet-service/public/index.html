Amazon Return Label Printer

A free, open-source browser extension by Florian Schneider

For Amazon.de returns: print only what the parcel counter needs on a single page, or put the DHL return QR code into Google Wallet and show it from your phone. No paper, no screenshots.

Get it for Firefox Source code on GitHub

How the Google Wallet pass works

  1. On the Amazon.de return page you click Google Wallet. Nothing happens without that click.
  2. The extension reads the DHL return QR code Amazon shows on that page, plus the return number, expiry date and item title.
  3. This server (wallet.infraviored.com) signs a Google Wallet pass with exactly that QR code and hands back a link to Google's "Save to Google Wallet" page.
  4. You save the pass and scan it at the DHL counter.

One pass per return, a generic pass with the QR code, return number, carrier and expiry date. The pass expires on its own after the return deadline. No accounts, no marketing, no notifications, no updates to saved passes.

Privacy

The server stores nothing and sets no cookies; printing never leaves your browser. Details: privacy policy.
